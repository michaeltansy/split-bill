# Bank Logos

These SVGs are **stylized text-mark placeholders** generated for v1, not official brand
assets. Swap each one for the official logo from the bank's brand kit before any public
launch, and confirm the license terms allow in-product display.

- `bca.svg` — placeholder for Bank Central Asia (BCA)
- `jago.svg` — placeholder for Bank Jago
- `gopay.svg` — placeholder for GoPay (PT Dompet Anak Bangsa / Gojek)

`Other` is intentionally logo-less — `BankInfoCard` renders a neutral fallback.
